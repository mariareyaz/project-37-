# Machine Learning Models for Preterm Birth Risk Prediction & Clinical Intervention

This repository contains the data analysis and predictive modeling codebase for evaluating clinical risk indicators and molecular biomarkers associated with preterm birth.

## Overview
Preterm birth remains a leading cause of neonatal morbidity. This project implements a machine learning framework designed to integrate maternal clinical risk factors and molecular biomarker parameters to improve early risk prediction and support precision clinical interventions. 

*Developed as part of the Harvard Health Systems Innovation Lab Hackathon & E-Poster Presentation (2026).*

## Features & Workflow
- **Data Preprocessing & Feature Engineering:** Handling clinical and biomarker features, missing data imputation, and feature scaling.
- **Model Training & Evaluation:** Implementation of supervised classification algorithms (e.g., Logistic Regression, Random Forest, XGBoost) to evaluate prediction metrics.
- **Performance Analysis:** Model evaluation using ROC-AUC, sensitivity/specificity curves, and feature importance analysis.
